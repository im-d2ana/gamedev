# PLATFORM JUMP

## Что это за игра?

PLATFORM JUMP — 2D-платформер на Phaser, в котором игрок управляет персонажем, автоматически отскакивающим от платформ. По мере продвижения вверх генерируются новые платформы, некоторые из них исчезают после использования, а на пути встречаются движущиеся враги.

Исчезающие платформы и враги появляются со второй фазы игры, которая начинается при 10 очках.

## Как управлять?

- **← / →** — движение влево и вправо.
- **A / D** — альтернативное управление движением.
- **P** — пауза и продолжение.

Прыжки выполняются автоматически, отдельная клавиша для прыжка не нужна.

## Как запустить?

```bash
npm install
npm run dev
```

Проверка и сборка:

```bash
npm run typecheck
npm run build
```

## Что должен делать игрок?

- Перемещаться между платформами и подниматься как можно выше.
- Выбирать путь между платформами.
- Избегать врагов.
- Учитывать, что некоторые платформы исчезают после использования.
- Набирать очки за каждую достигнутую платформу.

Игра заканчивается при падении или столкновении с врагом. После отображения результата игра автоматически перезапускается.

## Что такое фаза 2?

- Фаза 1 длится до 10 очков: все платформы обычные, врагов нет.
- При 10 очках появляется надпись «ФАЗА 2», и игра усложняется: появляются враги и исчезающие платформы, а враги двигаются быстрее.
- После перезапуска игра снова начинается с фазы 1.

## Что уже реализовано?

- Автоматические прыжки и бесконечная генерация платформ.
- Пауза и продолжение.
- Фаза 2, которая запускается по счёту.
- Рост сложности с высотой.
- Конец игры, результат и перезапуск.
- Игровые настройки собраны в `src/game/GameConfig.ts`.

## Что пока не реализовано?

- Полностью проверенная и сбалансированная генерация платформ для длительного прохождения.
- Проверка проходимости прыжков на разных участках игры и корректировка расстояний между платформами при необходимости.
- Подбор сложности под сессию на 3–5 минут.
