## Практика 2 / домашняя работа №2

### Добавлено

- Пауза и продолжение по `P`. Под паузой заморожены физика, таймеры, ввод, генерация и счёт.
- Фаза 2 с баннером «ФАЗА 2». Меняются скорость врагов, шанс появления врагов и шанс исчезающих платформ.
- Новое условие запуска фазы 2: по счёту (`PHASE_2_SCORE = 10`), а не по времени.
- Враги и исчезающие платформы появляются только со второй фазы. При входе в фазу 2 платформы выше экрана генерируются заново, чтобы опасности появились сразу.

### Рефакторинг

- Из `GameScene.ts` вынесены:
  - `difficulty.ts` — расчёт шансов врагов и исчезающих платформ;
  - `LevelGenerator.ts` — раскладка платформ по X;
  - `enemies.ts` — создание, движение и удаление врагов.
- Фаза передаётся в модули параметром, а не читается из сцены.

### Настройки

- Все числовые параметры баланса собраны в `GameConfig.ts`.

### Исправленные ошибки

- После конца игры игрок больше не подпрыгивает от платформ и не меняет счёт.
- Состояние паузы сбрасывается при перезапуске.

### Проверено

- `npm run typecheck` и `npm run build` проходят без ошибок.

### Известные проблемы

- Проходимость платформ на большой высоте не проверена автоматически.
- Баланс на сессии 3–5 минут подобран вручную и требует проверки.
- Некоторые числа (задержки перезапуска и исчезновения платформы) остались в `GameScene.ts`.
